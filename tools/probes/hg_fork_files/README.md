# hg_fork_files

`sh same_src.sh <repo>...`: are the src/ .sfd/.vfb files of a googlefonts fork byte-identical (git blob ids) to googlefontdirectory-hg at 52f780bc, the revision google/fonts recorded? Backs the "hold the same files" sentence tools/metadata.py (legacy_fork) writes. results-2026-11-20.txt: Krona One, Ovo, Pompiere, Short Stack, Sonsie One, 12 of 12 files same.
