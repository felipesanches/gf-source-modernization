# Re-probe of the census's binary-only families never landed (2026-11-12)

Question: of the 42 census families the screen (`../screen-2026-10-13.tsv`) found BINARY-ONLY and
that no family table holds, which convert from their shipped binaries now? 13 were probed once on
2026-10-13 (`../probe-batch-2026-10-13.tsv`); 12 never were. Left out: Noto CJK x10 (built by
notofonts/noto-cjk from Adobe's CID-keyed Source Han), Libre Barcode x7 (generated by
graphicore/librebarcode's Node.js tool) and WDXL Lubrifont x3 (an AFDKO CID pipeline from a
FontLab .vfc master): each has a real build pipeline upstream, so converting its binaries is a
decision, not a probe.
