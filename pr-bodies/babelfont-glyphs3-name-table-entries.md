Title: glyphs3: write names Glyphs cannot derive as Name Table Entry

Body:

Glyphs derives name IDs 1, 2 and 4 from the family and style name, and has no property for a full name that differs (postscriptFullName is the CFF name, which compilers do not use for ID 4). So a font whose names differ, e.g. full name "Lekton-Bold" or style "Book", lost them on export. For a single-style font the writer now emits those as "Name Table Entry" parameters, which glyphsLib and fontc both honour; fonts with several instances are left alone, since the parameter applies to all of them.
