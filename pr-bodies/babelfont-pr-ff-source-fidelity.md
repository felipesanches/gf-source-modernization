Title: Add opt-in filters that keep what a FontForge source states

Body:

Five opt-in filters:

- `--drop-alternate-unicodes`: drop AltUni2 alternate codepoints, keeping the Encoding one (the inverse of `--add-legacy-duplicate-cmap`).
- `--reverse-path-direction`: reverse every closed contour, for a font whose mixed directions must be kept.
- `--keep-source-glyph-names`: set "Don't use Production Names".
- `--keep-source-advances`: mark an uncategorised glyph with an advance as a base, so it is not zeroed as a mark by its name.
- `--snap-component-transforms`: in glyphs FontForge exports as composites, snap near-integer scales and round offsets with rint, as `dumpcomposite()` does.

Also, compiling a TTF now honours an enabled "Don't use Production Names".
