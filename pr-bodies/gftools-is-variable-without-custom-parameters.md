Title: builder: a .glyphs source without customParameters is not variable

Body:

`File.is_variable` reads the font-level `customParameters` list of a `.glyphs` file, which a single-master file need not have. Since 0.10.0 the fontc path asks every source whether it is variable (`modify_config` -> `will_build_variable_font`), so `gftools builder --experimental-fontc` (and `--experimental-simple-output`) crash on such a file with `KeyError: 'customParameters'`.

fontc_crater shows it: Katibeh (google/fonts `ofl/katibeh`, source https://github.com/Tarobish/Katibeh) builds in crater's gftools mode with gftools 0.9.93 and fails with 0.10.0, which blocks crater from moving its gftools pin.

This treats a missing list as empty, and adds a test with a minimal single-master `.glyphs` file (it fails without the change). tests/test_builder.py: 12 passed.
