Metadata only, no font binaries change. One commit per family: the METADATA.pb `source { }` block and upstream_info.md. Follows #11162 and #11218.

Each family now points at a new repository, https://github.com/googlefonts/<family>, whose history is the original files imported unmodified (the FontForge `.sfd` from googlefontdirectory-hg, or the shipped fonts where no source was ever published), the Unified Font Repository template, one commit per documented `.sfd` edit, and the conversion to `.glyphs` last. METADATA.pb records that conversion commit.

- 9 families, 29 styles. From `.sfd`: Mr Bedfort, Nixie One, Nova Script, Rouge Script, Smokum. From the shipped fonts (babelfont-rs's TTF reader, no filters): Averia Libre, Averia Sans Libre, Averia Serif Libre, Sansation.
- Converted with babelfont-rs: Simon's main 5ff5bf0 for the `.sfd` families; branch 2026-11-02 of https://github.com/felipesanches/babelfont-rs (26fdcfa: main plus the name changes proposed in #117) for the Averias; branch 2026-10-22 (ed59a63, the reader changes merged since as #131) for Sansation. Built with gftools-builder (gftools-rust 1e638bd, fontc 1.0.0).
- Every build matches the binaries google/fonts ships (0 blocking rows under the table gate, exactly the shipped codepoints, functionally equivalent in cmap, shaping, rendering, names, line spacing, advances and GDEF) except one to three known differences per family, each reviewed, kept, and listed in its upstream_info.md and repository README: legacy `kern` tables rebuilt as GPOS kerning (the Averias, Sansation, Smokum); glyphs the FontForge export drew shifted from their outlines by a wrong left side bearing, now placed as designed (Mr Bedfort, Nixie One, Rouge Script); the italic flag fontc derives from the italic angle (Nova Script, Sansation Light Italic).
- The previous source blocks and the earlier investigations are kept in each upstream_info.md.
