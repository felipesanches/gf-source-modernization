Title: glyphs3: write an axis without a map when it would not read back

Body:

> **Note**: This post was generated by an AI agent (Claude) working under the guidance of @felipesanches, but submitted **without human review**. @felipesanches himself would still need to participate in the PR thread if he wants to contribute to the review.

An axis without a map has equal user and design coordinates, and the Glyphs writer left it out of Axis Mappings, expecting it to read back as an identity. But with no Axis Mappings or Axis Location the loader takes weight axis user locations from the instances' weight classes, 400 when unset. A variable TrueType font read by the TTF reader (its instances carry no weight class) came back with every instance at user 400, so wght 100-400-900 read back as a single point and the font could not be built.

The writer already writes a map the loader would not derive; it now applies the same check to an axis without a map, and writes the identity when the loader would derive something else.

New test unmapped_axis_survives_a_glyphs_round_trip fails without the change; the other tests are unchanged.
