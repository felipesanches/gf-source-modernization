Reworked as a generic `--add-notdef` filter with nothing FontForge-specific in it: when a font has no `.notdef`, it adds one drawn as a hollow rectangle sized from the em and the ascender (stem em/30, height min(2*em/3, ascender)), with the shared advance if the font is monospaced. `--add-notdef=empty` also replaces a `.notdef` that draws nothing; that is not the default, because an empty `.notdef` may be intended. The one-width helper went back into the OS/2 defaults filter, so this PR no longer touches it, and the module doc you quoted is gone.
