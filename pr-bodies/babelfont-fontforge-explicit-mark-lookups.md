FontForge exports each SFD anchor lookup (mark-to-base, mark-to-ligature, mark-to-mark, cursive) as its own lookup, with one subtable per SFD subtable, the lookup's flags and only its own feature/script/language registrations; its coverage is every glyph carrying an anchor of the subtable's classes, whatever the glyph's GDEF class. A feature writer regroups the anchors by name, registers them for every language system and leaves out glyphs without a GDEF class, so releases with unclassed bases (Thabit: peh, tehring, uniFB58 and 79 more) or mark lookups registered for one script only (Cardo) shape differently. The SFD reader now records these lookups, and this opt-in filter writes them as explicit feature code and removes the mark and curs writers from the ufo2ft featureWriters list. With it, Thabit and Thabit-Oblique go from 491 differing shaped runs to 0, Cardo-Regular from 2 to 0 and Lohit-Bengali from 1666 to 0, with no regressions in eight other FontForge families.
