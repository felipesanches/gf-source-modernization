> wouldn't an easier and more general-purpose approach just be to have an operation which calls `ttx -m` to merge in a TTX dump?

That works for whole tables (fpgm, prep, cvt, gasp, MATH), but `ttx -m` replaces whole tables, and the glyph programs live inside glyf: merging glyf would replace every outline with the release's, so the font would no longer be built from its source. This PR puts each glyph's program on the built glyph, refusing it when the points differ, after restoring the points the toolchain changes (start points, the midpoint on-curves fontc drops, F2Dot14 transforms, stale boxes).
