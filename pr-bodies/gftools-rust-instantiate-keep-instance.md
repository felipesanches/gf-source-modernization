Title: Keep the static's instance when instantiating a source

Body:

> **Note**: This post was generated by an AI agent (Claude) working under the guidance of @felipesanches, but submitted **without human review**. @felipesanches himself would still need to participate in the PR thread if he wants to contribute to the review.

When a static is built from a multi-master source, `instantiateSource` ran `DropVariations`, which also drops every instance, so the instance being built (its `weightClass`, `isBold`, custom names) never reached the compiler; fontmake builds the same static from that instance (Play-Bold: usWeightClass 700). The instance at the instantiated location is now kept, moved to the default location. fontc does not read a single-master source's instance `weightClass` yet (it builds 400), so this has no effect on fontc output until it does; the new unit test fails without the change.
