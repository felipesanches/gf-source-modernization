Title: glyphs3: write the PostScript name as postscriptFontName

Body:

The Glyphs 3 writer stored the PostScript name (name ID 6) as `postscriptFullName` and name ID 20 as `postscriptFontName`, and the reader mirrored that. Glyphs and glyphsLib read `postscriptFontName` as the PostScript name and `postscriptFullName` as the full name; fontc reads only `postscriptFontName`. So a converted font lost its stated PostScript name and compilers derived Family-Style instead.

This writes `postscript_name` as `postscriptFontName` and `full_name` as `postscriptFullName`, reads both (and the localized `postscriptFullNames`) back the same way, and no longer writes name ID 20, which has no Glyphs property.

Tests: two new unit tests (writing at font and instance level, reading) fail on main and pass here.
