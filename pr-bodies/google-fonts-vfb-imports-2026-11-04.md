Metadata only, no binaries change. One commit per family (METADATA.pb `source` block + upstream_info.md). Follows #11225.

Each family's only published source is a `-TTF.vfb` (in librefonts for 25 families, googlefontdirectory-hg for 31), a FontLab import of the shipped fonts rather than a design source (#10490, "batch-converted from the binary files"). So, as for the binary-only families, each now points at a new https://github.com/googlefonts/<family> repository: the shipped fonts imported unmodified, the Unified Font Repository template, then the conversion to `.glyphs`. METADATA.pb records the conversion commit (for Alfa Slab One, the documented commit after it that states the release's GDEF glyph classes). The `.vfb` is listed under "Earlier sources" in each upstream_info.md.
