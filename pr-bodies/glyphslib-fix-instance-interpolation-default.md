Glyphs 2 omits an instance's `interpolationWeight`/`interpolationWidth` when it is 100,
as it omits a master's `weightValue`/`widthValue`. The instance fields defaulted to 0, so
e.g. a Bold instance at the Bold master's default location was placed at weight 0, on top
of the Regular. They now default to 100, like the master fields.

Seen in gftools-builder3 static builds of a two-master Glyphs 2 source: the two statics
land on the same location and only one font file is written.
