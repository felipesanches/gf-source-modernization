A compiler that finds no category on a glyph may take one from its name and zero its advance as a mark, even when the source gives it a width (e.g. commaaccent); FontForge's export keeps every advance the source states. This opt-in filter records such uncategorised glyphs with an advance as bases, so a converted source keeps them. Run --infer-mark-category first, which categorises real marks from their anchors.
