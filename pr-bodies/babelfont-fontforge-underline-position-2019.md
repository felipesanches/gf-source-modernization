FontForge's TTF exporter writes post.underlinePosition as UnderlinePosition - UnderlineWidth/2 up to tag 20170731 and as UnderlinePosition + UnderlineWidth/2 from 20190317 on (commit 9f667c9c), truncating towards zero; the filter only implemented the older rule. `--fontforge-underline-position=20190317` now applies the newer one, while the bare flag (or `=20170731`) keeps the existing behaviour. Comic Relief (SFD -185/175, release -97) needs the newer rule; the older one gives -272.
