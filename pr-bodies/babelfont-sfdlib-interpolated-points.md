Title: Add --sfdlib-interpolated-points

In a quadratic SFD layer, sfdLib's sfd2ufo emits the end point of a `c` segment whose flags carry SFD_PTFLAG_INTERPOLATE (0x80) as an off-curve point at the same position, and a flagged closing segment does the same to the start point. Binaries built from that conversion therefore have control points where the SFD has on-curve points, which babelfont's faithful reading cannot reproduce. This opt-in filter applies sfdLib's rule using the point flags the SFD reader already records (the decimal flags before any `x<hintmask>`). With it, both Comic Relief styles (built with sfdLib 2.0.0 and ufo2ft) render identically to the release: 0 of 600 glyphs differ, against 52 (Regular) and 501 (Bold) without it.
