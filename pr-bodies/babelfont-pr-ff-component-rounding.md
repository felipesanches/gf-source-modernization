FontForge's TrueType export snaps a near-integer component scale to the integer (a mirror stored as -0.999939 is written as -1) and rounds offsets with rint (44.5 to 44). Converted as-is, fontc gets -0.9999 and 44.5: it writes the scale as -0.99988 and rounds the offset up to 45, so e.g. Six Caps' Emacron macron sits one unit right of the released font. This opt-in filter applies the exporter's rounding to the layers FontForge exports as composites, so a converted source rebuilds what FontForge shipped.
