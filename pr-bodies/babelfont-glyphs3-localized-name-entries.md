Glyphs 3 has localized font properties only for some name IDs (copyrights, familyNames, designers, ...) and only for the languages it has a code for, so a localized subfamily (ID 2) or full name (ID 4), or a name in a language such as Spanish (Mexico), was silently lost. For a single-style font the writer now emits each such record as a "Name Table Entry" custom parameter `<id> 3 1 <language ID>; <value>`, which fontc applies verbatim; US English is left to the existing properties, and fonts with several styles get none because the parameter applies to every instance. With the LangName reader fix, Comic Relief's 24 localized subfamily names reach the compiled font, matching the release.
