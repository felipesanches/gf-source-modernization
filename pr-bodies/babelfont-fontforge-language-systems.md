Body:

A feature file allows no script or language statement inside `aalt`, so `aalt` is registered under every `languagesystem`, while FontForge registers it only for the language systems its lookups name (Poly-Italic: latn/dflt, not latn/ROM). Every other FontForge lookup is already written with explicit `script`/`language` statements, so when the font has no kerning and no anchors (the features a compiler generates from the declarations) only `aalt`'s language systems are declared; otherwise all of them stay declared and a warning is logged. With this change Poly-Italic's GSUB registers every feature where the release does.
