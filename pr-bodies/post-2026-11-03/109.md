One more commit: the carets now go both ways. The SFD reader makes each `LCarets2` entry a `caret_<n>` anchor, the Glyphs convention for a ligature caret, with nothing SFD-specific attached to it; the SFD writer writes `caret_<n>` anchors back as `LCarets2` (with `LigCaretCntFixed: 1` when a caret is at 0) instead of as anchor points, so a font from any format keeps its carets in SFD. `test_ligature_carets_survive_an_sfd_roundtrip` covers it.
