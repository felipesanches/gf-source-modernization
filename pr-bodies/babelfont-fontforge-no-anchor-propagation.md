FontForge exports only a glyph's own anchors, so a glyph built from references is not a mark base unless it has anchors itself; a Glyphs compiler propagates anchors from components and makes it one. This opt-in filter sets the font custom parameter Propagate Anchors to false, which fontc honours. In Cardo-Regular it brings the shaping differences against the FontForge release from 984 to 2 runs (of 4.4 million).
