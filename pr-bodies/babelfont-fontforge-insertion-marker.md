Body:

The SFD reader marked feature blocks with "# Automatic code start", but ufo2ft and fontc only recognise "# Automatic Code" (the spelling subsetlayout.rs already uses). With the wrong spelling the compiler treats the block as hand-written and generates no kern/mark/mkmk/abvm/blwm lookups for it; Lohit-Bengali lost its abvm/blwm positioning.
