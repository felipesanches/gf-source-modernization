Title: ttf: read named instances at their fvar coordinates

Body:

fvar states a named instance in user coordinates. The TTF reader took them through skrifa's normalized location (F2Dot14) and back to design coordinates, so an instance at wght 700 of an axis 100-400-900 came out at 700.0183, and an instance read this way no longer sits where the font puts it.

The reader now takes the instance's user coordinates and maps them to design coordinates with the axis.

New test test_instance_locations_are_fvar_coordinates (Variable.ttf, added to make_fixtures.py) fails without the change; the other tests are unchanged.
