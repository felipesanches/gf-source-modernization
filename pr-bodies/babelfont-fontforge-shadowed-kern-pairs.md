Body:

A FontForge pair lookup can hold the same glyph pair in two subtables (e.g. Kerns2 in the first, PairPos2 in a later one); only the first applies. The reader passed both on (one to the kerning model, one to an FEA lookup), so the compiled font kerned the pair twice. Glyph pairs an earlier subtable of the same lookup already holds are now dropped. Fixes doubled kerning in Italiana and Sanchez.
