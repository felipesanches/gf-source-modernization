Each family's only published source is a `-TTF.sfd` in googlefontdirectory-hg, a FontForge import of the shipped fonts rather than a design source (#10490, "batch-converted from the binary files"). So, as for the binary-only families, each now points at a new https://github.com/googlefonts/<family> repository: the shipped fonts imported unmodified, the Unified Font Repository template, then the conversion to `.glyphs`. The `.sfd` is listed under "Earlier sources" in each upstream_info.md.
