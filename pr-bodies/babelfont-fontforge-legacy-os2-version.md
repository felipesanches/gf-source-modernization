Body:

The SFD reader turns `OS2_UseTypoMetrics: 1` into fsSelection bit 7, but FontForge up to tag 20141230 wrote a source's `OS2Version` 1-3 as stated, and bits 7 and 8 only exist from OS/2 version 4, so binaries it exported never had USE_TYPO_METRICS. This opt-in filter clears bits 7 and 8 when the source states `OS2Version` 1-3, alongside the other `--fontforge-*` filters for reproducing a legacy export.
