Title: Point 14 more binary-only families at new .glyphs sources in googlefonts/*, with their known differences disclosed

Body:

> **Note**: This post was generated by an AI agent (Claude) working under the guidance of @felipesanches, but submitted **without human review**. @felipesanches himself would still need to participate in the PR thread if he wants to contribute to the review.

Metadata only, no font binaries change. One commit per family: the METADATA.pb `source { }` block and upstream_info.md. Follows #11162.

No source of these families was ever published: the fonts Google Fonts ships were their only form. Each now points at a new repository, https://github.com/googlefonts/<family>, whose history is the shipped fonts imported unmodified, the Unified Font Repository template, and the conversion to `.glyphs` last. METADATA.pb records that conversion commit.

- 14 families, 23 styles: Alef, the ten IM Fell families (Double Pica, DW Pica, English, French Canon, Great Primer, each with its SC), Jomolhari, Nanum Gothic Coding, Nanum Myeongjo.
- Converted with babelfont-rs's TTF reader, no filters: babelfont 26fdcfa, branch 2026-11-02 of https://github.com/felipesanches/babelfont-rs (simoncozens/babelfont-rs main plus the name changes proposed in #117). Built with gftools-builder (gftools-rust 1e638bd, fontc 1.0.0).
- Every build matches the binaries google/fonts ships (0 blocking rows under the table gate, exactly the shipped codepoints, functionally equivalent in cmap, shaping, rendering, names, line spacing, advances and GDEF) except two or three known differences per family, each reviewed, kept, and listed in its upstream_info.md and repository README: hinting by ttfautohint instead of the release's instructions (Alef, Jomolhari, the Nanums); `head` fontDirectionHint 2 where the release states 0 or 1 (a `.glyphs` source cannot state the field; Alef, the IM Fells, the Nanums); legacy `kern` tables rebuilt as GPOS kerning, which positions combining marks differently from the release's shaper fallback (the IM Fells); no `PCLT` table (Jomolhari).
- The previous source blocks and the earlier investigations are kept in each upstream_info.md.

Tools, plans and logs: https://github.com/felipesanches/gf-source-modernization at 8caaf25.
