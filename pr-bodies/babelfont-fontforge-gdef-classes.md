FontForge's exporter gives every glyph a GDEF class: an explicit GlyphClass wins; otherwise .notdef has none, a glyph whose first non-cursive anchor is a mark anchor is a mark, a ligature substitution's result is a ligature, and everything else is a base. A converted source cannot say "base" for a glyph without anchors, so the compiled font loses these classes or makes accents marks by their names. The SFD reader now records FontForge's class per glyph, and this opt-in filter writes them as an explicit `table GDEF { GlyphClassDef ... }`. The rule reproduces the shipped GlyphClassDef of 120 of 122 FontForge-exported releases checked.
