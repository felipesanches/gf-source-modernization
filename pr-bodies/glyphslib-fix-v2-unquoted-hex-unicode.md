Title: glyphs2: read an unquoted all-digit hex unicode as hex

Body:

Glyphs 2 writes `unicode = 2013;` unquoted when every hex digit is decimal. `visit_u64` formatted the integer back as hex and parsed it as hex, a no-op, so the en dash came out as U+07DD. The digits are now read as hex. This hits U+2013/2014, U+2018/2019, U+2020-2022, U+2026 and U+2030 in any Glyphs 2 source.

New test `test_v2_unquoted_all_digit_hex_unicode`. The 4 `test_load_upgrade` failures are pre-existing (they need a `resources/upgraded/` directory).
