Three opt-in filters for the OS/2 and post values FontForge's TTF exporter computes. `--fontforge-os2-defaults` and `--fontforge-height-glyph-count-mean` fill values the source does not state; `--fontforge-underline-position` converts the UnderlinePosition the source states.

- `--fontforge-underline-position`: FontForge's UnderlinePosition is the underline's centre, post.underlinePosition its top; applies `dumppost()`'s rule up to tag 20170731, position - thickness/2 in real arithmetic truncated towards zero. FontForge reversed the sign in commit 9f667c9c (fontforge/fontforge#3389, first in tag 20190317), so the flag is for a binary exported by an older FontForge, whatever the export date.
- `--fontforge-os2-defaults`, sub/superscript and strikeout: when the source has no OS2SubXSize (FontForge's `subsuper_set`), all ten from `SFDefaultOS2SubSuper` (tottf.c), with the x offsets derived from the y offsets already truncated to 16 bits.
- `--fontforge-os2-defaults`, PANOSE: as `SFDefaultOS2Info` computes it. `OS2WeightCheck` sets byte 2 from the Weight: name and then from the FontName; "script" in the FontName (without "sans") sets byte 0 to 3; FontName width words set byte 3, and one shared advance (`CIDOneWidth`) sets it to 9.
- `--fontforge-os2-defaults`, x-height and cap height: each one the source does not state, as `setos2` fills it from `SFXHeight`/`SFCapHeight` (`SFStandardHeight`, splinefont.c).
- `--fontforge-height-glyph-count-mean`: the x-height and cap height as a FontForge built before 2012-05-14 (commit 4d34d21ef866) computed them, the sum of the distinct round or pointed tops divided by the glyph count. Run it before `--fontforge-os2-defaults`.
