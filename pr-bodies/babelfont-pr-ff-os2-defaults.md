Three opt-in filters that fill the OS/2 and post values FontForge's TTF exporter
computes, for converting a FontForge source whose exported binary must be reproduced.

- `--fontforge-os2-defaults`: fills the x-height, cap height and PANOSE the source does
  not state, and the ten sub/superscript and strikeout values as a group when
  OS2SubXSize is absent (`SFDefaultOS2Info`, `SFDefaultOS2SubSuper` and `setos2` in
  tottf.c; `SFStandardHeight` in splinefont.c).
- `--fontforge-height-glyph-count-mean`: the x-height and cap height as FontForge
  computed them before 4d34d21ef866 (2012-05-14), dividing by the glyph count. Run it
  before `--fontforge-os2-defaults`.
- `--fontforge-underline-position`: converts UnderlinePosition (the centre) with
  `dumppost()`'s rule up to tag 20170731, position - thickness/2; FontForge changed it
  in 9f667c9c (first in 20190317).

Not modelled, and said so in the rustdoc: sources without FontForge's `pfmset`, OS/2
version-1 exports, and fractional metrics (the reader drops a fractional underline
value and rounds the italic angle).
