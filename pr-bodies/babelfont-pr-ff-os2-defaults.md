Three opt-in filters that fill values FontForge's TTF exporter computes:

- `--fontforge-os2-defaults`: x-height, cap height and PANOSE when the source does not state them, and the sub/superscript and strikeout group when OS2SubXSize is absent (`SFDefaultOS2Info`, `SFDefaultOS2SubSuper`, `setos2`).
- `--fontforge-height-glyph-count-mean`: x-height and cap height as FontForge computed them before 2012-05-14 (4d34d21ef866). Run it before `--fontforge-os2-defaults`.
- `--fontforge-underline-position`: position - thickness/2, FontForge's rule up to 20170731.

What is not modelled (pfmset, OS/2 version 1, fractional metrics) is in the rustdoc.
