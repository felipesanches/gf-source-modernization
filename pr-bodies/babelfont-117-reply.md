One more commit: a font with Macintosh name records (most fonts from the TTF reader) got Windows entries with a Macintosh language ID, such as `1 3 1 0x0000; Gugi`. A Macintosh record's name is keyed by the BCP-47 code of its Macintosh language ("en" for language 0), and the language lookup matched those codes too. It now looks up only Windows language IDs, and skips a Macintosh language without a warning; `test_a_macintosh_name_gets_no_entry` covers it. With this, Gugi converted from its release keeps its Korean names (Windows language 0x0412).
